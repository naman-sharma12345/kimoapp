## Polish decisions

- Headlines balance; body paragraphs wrap prettily. Changing numbers use tabular figures. Long labels in search/project title truncate and expose the full value through title text; original user filenames/copy remain intact.
- Play icons move one CSS pixel right. Existing type, palette, radii, spacing and motion tokens are retained. Named new sizes are the brief's 680px privacy measure and 8px coach arrow; remaining geometry uses existing controls/space tokens.
- The user's earlier composer focus-highlight and native resize-handle removals remain in force. Other controls keep visible keyboard focus rings. High-contrast mode strengthens secondary text and borders; forced-color browser behavior remains native.
- Historical cuts disable edit entry points, undo/redo, agent controls, uploads, inspector and timeline mutation. Playback and switching/restoring cuts remain available. A restore is an ordinary durable user-op batch against the live session.
- No UI console.log remains. The small development logger records only fixed error codes and is silent in production. UI voice is lowercase; filenames, user text, font-family identifiers, technical units and upstream model identifiers retain their data semantics.
