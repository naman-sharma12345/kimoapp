# Color and look

First make it correct, then give it a look. Subtle beats strong. If you are unsure about the footage's exposure (you can't see it), keep corrections small and say the user can tweak.

## Correction (one per scene, consistent across clips of the same camera)

- Slightly dark phone footage: exposure +0.1 to +0.25, contrast 1.05.
- Flat/log-looking footage (user says "log" or "flat"): contrast 1.2 to 1.3, saturation 1.15 to 1.25.
- Too warm indoors: temperature -0.05 to -0.1. Too cold outdoors/overcast: +0.05 to +0.1.
- Match clips in a sequence: same grade values on every clip from the same source and lighting.

## Looks (pick one per video, apply to all A-roll clips, or put a single adjustment clip spanning the timeline on a top video/overlay track)

- Clean creator: contrast 1.08, saturation 1.06, sharpen 0.15.
- Warm film: lut 'warm film', grain 0.05, vignette 0.2.
- Teal & orange blockbuster: lut 'teal & orange', contrast 1.12, vignette 0.25.
- Moody: exposure -0.15, contrast 1.15, saturation 0.85, vignette 0.35.
- Black and white documentary: black_and_white + contrast 1.2 + grain 0.08.
- Never push saturation above 1.3 on footage with faces; skin goes orange.
