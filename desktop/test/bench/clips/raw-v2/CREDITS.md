## Acquisition tools

The existing FFmpeg/Whisper tools do media inspection and local transcription. The Cinestudy acquisition job alone uses a SHA256-verified standalone `yt-dlp.exe` release 2026.10.26 from the [official project](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26). It is a CI-only source-acquisition tool, with no account/cookies, no new app package dependency, no Python scripts and no installer/release changes. It is not bundled into kimo. Source downloads make no AI requests and never change the cumulative spending ledger.
