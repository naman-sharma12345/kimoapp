Coverage gaps: TH-1 is a lower-resolution interview; TH-2 is an event interview, not verified outdoor walking/wind footage; TUT-1 has narration without face cam; VLOG-1 is a constructed proxy; POD-1 uses alternating interview framings rather than a purpose-shot podcast; MUSIC-1 is already edited/scored. These cases exercise the pipeline without establishing full walk-and-talk, face-cam or podcast coverage. Better footage must be a separately versioned manifest, never silently changed bytes.
