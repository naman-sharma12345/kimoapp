First Windows release of kimo: one installer with the real kimo v6 engine, FFmpeg and whisper running on your PC.

- Drag in files or folders; local library with history, edit script and live op log
- AI edit (script → kimo tools → render → check 3 frames + audio → fix, up to 3 passes)
- Captions only, fully offline
- YouTube 16:9 (1080p/4K), Shorts/Reels/TikTok 9:16, square, 4:5
- Batch queue: one prompt, many videos
- GPU encode for upload copies (NVENC / Quick Sync / AMF, CPU fallback)
- Auto-update from GitHub Releases
